# medjugorjereisen.de

Webseite von Medjugorje Reisen (Reiner Wettcke).

- Inhalte: `daten/botschaften.json` (Monatsbotschaften), `daten/reisen.json` (Reisetermine), Seitentexte in `werkzeug/*_inhalt.html`
- Seiten neu erzeugen: `python3 werkzeug/bauen.py`
- Gestaltung: `style.css`, Schriften lokal in `schriften/` (SIL Open Font License)
